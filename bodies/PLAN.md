# Plan

## Phase 1

- Write the model equations and calibration notes.
- Create a seed body catalog that is easy to inspect.
- Add a tiny validation table for Earth, the Moon, and a few large asteroids.

## Phase 2

- Expand the catalog to all major planets and moons.
- Parse the JPL DASTCOM5 data locally for asteroid mass and radius fields.
- Add derived fields for accessible shell thickness and reachable mass.

## Phase 3

- Produce an XKCD-style area reference chart.
- Produce the new mineable-mass chart.
- Add a shallow strip-mining variant that emphasizes pressure-limited depth.

## Phase 4

- Check the Earth calibration against known mine depths.
- Compare a few representative bodies against intuitive limits:
  - large planets should be pressure-limited only at very shallow depths
  - small bodies should often be radius-limited before pressure or temperature matter
