# Definition Data

This directory holds the curated body catalog definition.

It is the place for stable, human-authored records with explicit provenance
links back to `data/origin`.

Fields here should distinguish between:

- source-truth values, such as mass and radius
- computed values, such as density and gravity
- model-assumption values, such as excavation density or thermal caps

Surface-usability assumptions for the strip-mining variants live in a
separate definition table so the Earth land fraction and the Venus exclusion
stay explicit and easy to revise.
